# Together

## Watch Party System

This project is a watch party platform that allows users to watch movies, TV shows, cartoons, or videos together in real time, even if they are in different physical locations.  Users can synchronize playback, chat, and interact while watching, creating a shared viewing experience similar to watching together in person.

##  Tech Stack
- PHP
- JavaScript
- HTML

## High-Level Features
- User signup/ Login
- Video synchronization
- Real-Time video/ Text chatting
